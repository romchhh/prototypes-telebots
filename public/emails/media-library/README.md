# Медіа для листів Eliminal

Беріть файл звідси і копіюйте в папку листа. У самому листі лишайте коротке ім’я (`hero.jpg`), не шлях сюди.

Папки: `бренд` · `гель` · `verde` · `іконки`. У `не-використовувати` лежать кадри, які в лист ставити не треба.

## бренд

Логотип, стрілка кнопки, хвиля закриття, іконки футера. `експорт-png` — ті самі знаки окремими PNG.
